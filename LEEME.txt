CUENTAFÁCIL - ETAPA 3 (proyecto completo)

PASOS (Windows). Abrir en VS Code la carpeta que contiene manage.py (CuentaFacil_Django_Etapa3):
1. python -m venv .venv
2. .\.venv\Scripts\Activate.ps1
3. python -m pip install -r requirements.txt
4. python manage.py migrate
5. python manage.py runserver 0.0.0.0:8000
6. En la PC:      http://127.0.0.1:8000/registro/
   En el celular: http://IP-DE-TU-PC:8000   (IP con:  ipconfig | findstr IPv4 ; misma red Wi-Fi)
Pruebas automáticas: python manage.py test   (deben pasar 30)
